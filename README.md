# ACOPERCYL - Asociación de COVID Persistente de Castilla y León

Sitio web oficial de la Asociación de COVID Persistente de Castilla y León (ACOPERCYL).

## 🚀 Objetivo
Brindar una plataforma de información, apoyo y visibilidad para las personas afectadas por COVID Persistente (Long COVID) en Castilla y León.

## 🛠️ Tecnologías
- HTML5 Semántico
- CSS3 Moderno (Custom Properties, Flexbox, Grid)
- JavaScript (ES6+)
- Despliegue: GitHub Pages / Vercel (Pendiente)

## 📊 Estado del Proyecto
- [x] **Diseño Visual & Branding:** Finalizado (Paleta verde menta, tipografía Outfit/Inter, fondos alternos refinados).
- [x] **Navegación & Estructura:** Menú simplificado (unificación de Nosotros con Objetivos, y Comunidad con Contacto) y scroll suave con barra de progreso.
- [x] **Formulario de Contacto:** Operativo vía Formspree con validación AJAX y seguridad Cloudflare Turnstile.
- [x] **Despliegue & Dominio:** Publicado en producción bajo dominio oficial: [acopercyl.org](https://www.acopercyl.org).
- [x] **CMS (Sveltia):** Totalmente integrado y operativo en local y producción para gestionar noticias, textos de la web y comunicados oficiales.
- [x] **Comunicados Oficiales:** Apartado para subir documentos PDF oficiales y mostrarlos en tarjetas premium clickables.
- [x] **SEO & Accesibilidad:** Datos estructurados Schema.org (JSON-LD), etiquetas Open Graph y Sitemap.xml.

## 📁 Estructura del Proyecto
- `index.html`: Página principal (Hero, Nosotros, Objetivos, Síntomas, Comunidad, FAQ, Contacto).
- `politica-privacidad.html`: Avisos legales y privacidad sincronizados.
- `admin/`: Configuración de Decap CMS (En pausa).
- `assets/css/`: Estilos CSS modernos.
- `assets/js/`: Lógica de navegación, cookies y formulario.
